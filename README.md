# Course Path Recommendation System

## 📌 Overview
This project recommends courses to students based on their **CGPA**, **completed course count**, and **interest area** using a Decision Tree Classifier.

## ⚙️ Features
- Machine Learning model (Decision Tree)
- FastAPI backend for predictions
- Interactive Swagger UI for testing
- Virtual environment support
